# 09. search: 범위 검색

단계: 1단계.

## 지금

`GET /search?q=&limit=`는 할 일과 **일간** 회고를 함께 찾는다(`search/CLAUDE.md`).
주간, 월간, 연간 회고와 주제는 찾지 않는다.

## 화면

Ctrl+K 검색과 명령(명세 1장 "검색과 명령"). 범위 탭: 전체, 할 일, 회고, 명령.
시안은 회고 목록에 주제도 함께 보여 준다(`d-retro2.html`의 회고 찾기 "회고 제목, 날짜, 내용, 주제").
"명령"은 FE 안에서만 처리한다.

## 바꿀 것

`GET /search`에 선택 파라미터 `scope`를 더한다.

| `scope` | 찾는 것 |
|---|---|
| (없음) | **지금 동작 그대로**: 할 일 + 일간 회고. 기존 호출과 계약 유지 |
| `all` | 할 일 + 모든 종류의 회고 + 주제 |
| `todo` | 할 일 |
| `retro` | 모든 종류의 회고(제목, 본문). 결과에 `retroType` |
| `topic` | 주제 이름과 설명 |

- 응답은 지금 모양에 `topics: [{ id, name, description }]` 묶음을 더한다(`scope`가 `all`, `topic`일 때만 채움).
- 회고 결과에 `retroType`을 더한다.
- `limit`은 묶음마다 적용한다.
- 휴지통(6단계) 이후 지운 것은 빠진다.

## 테스트

- `scope` 없이 부르면 결과가 지금과 같음(회귀)
- `retro`에서 주간 회고가 찾아짐
- `topic`에서 설명 일치
