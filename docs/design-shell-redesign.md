| 구분 | 내용 |

## 4. 화면 구조

```
┌ 레일(240) ─────┬ 메인 ────────────────────────────────────┬ 상세(360, 선택 시) ┐
│ ◆ ARCHIVE      │ [퀵 캡처: 내일 3시 PR 리뷰 #work      ⏎ ] │                    │
│ 대시보드        │ 2026년 11월  ‹ 오늘 ›   월 주 [일]   ⌘K │ 할 일 상세          │
│ ▸캘린더         │ ┌──────────────────────────────────────┐ │ 상태 / 시간 / 날짜  │
│ 할 일 · 회고    │ │ 08 ─────────────                      │ │ 연결된 커밋·PR      │
│ 설정            │ │ 09 ▌PR 리뷰            ░░ 커밋 3     │ │ 회고 메모           │
│ ─ 미니 월 ─     │ │ 10 ─────────  ◀ 지금 14:20 ──        │ │                    │
│  S M T W T F S │ │ 11 ▌스프린트 회의                     │ │                    │
│ ─ 배치 대기 ─   │ │ …                                    │ │                    │
│ ○ 문서 정리     │ └──────────────────────────────────────┘ │                    │
│ ○ 버그 수정     │ [하루 닫기 · 완료 4 / 계획 6 → 회고 초안]  │                    │

└────────────────┴──────────────────────────────────────────┴────────────────────┘
```

### 4.1 앱 셸
- 상단 가로 탭 → **좌측 레일**. 폭 240px, 접으면 56px 아이콘 레일. 모바일(≤40rem)은 하단 탭바 + 아젠다 리스트.
- 레일 구성: 브랜드 / 내비 5개 / 미니 월 / 배치 대기 / 하단(GitHub 동기화 칩, 알림, 사용자).
- 검색은 `Ctrl+K` 팔레트로 통합(기존 검색 로직 호출만 유지). 헤더 검색창은 제거.

### 4.2 메인 캘린더
- **일간**: 기본 뷰 후보. 08–22시 시간선, 지금 선(라벤더), 할 일은 체크박스 포함 블록.
- **주간**: 7열 시간 그리드 + 상단 종일/기간 레인(기간 할 일은 가로 바).
- **월간**: 지금의 큰 칸 격자를 "밀도 낮은 히트맵"으로. 칸에는 상태 점 최대 3개 + 개수, 칸 클릭 시 일간으로 이동. 미니 월과 역할이 겹치므로 월간 뷰는 확대 모드에서 주로 사용.
- 상태 필터와 개수(대기/진행/완료)는 툴바 우측에 한 줄 칩으로.

### 4.3 상세 패널
- 우측 고정 360px 슬라이드 인. 현재 기능(상태·시간·날짜 수정, 2단계 삭제) 그대로.
- 위쪽에 **연결된 활동**(커밋/PR)과 **회고 메모** 섹션 추가(차별점 참조).

### 4.4 상태 화면
로딩은 스켈레톤 행, 빈 상태는 "아직 계획이 없어요 + 퀵 캡처 포커스", 오류는 배너 + 재시도. 기존 로직의 상태를 그대로 표현만 바꾼다.

## 5. 우리만의 차별점: "계획 vs 실제, 그리고 하루 닫기"

다른 캘린더는 계획을 보여주는 데서 끝난다. ARCHIVE는 할 일·GitHub 연동·회고를 이미 갖고 있으므로 셋을 한 시간선에서 잇는다.

1. **실제 활동 레이어 (Ghost track)**: 시간선 오른쪽 가는 트랙에 그날의 커밋·PR을 점선 블록으로 겹쳐 표시. 계획 블록과 겹치면 "이 할 일에 연결됨" 점이 켜진다. 토글 가능, 기본 켜짐.
2. **하루 닫기 (Close the day)**: 일간 하단 바. 누르면 완료/미완료/이월을 한 번에 정리하고 미완료 할 일을 내일로 이월, 완료 항목+커밋을 묶어 **회고 초안**(기존 AI 요약 흐름 재사용)을 만든다. 달력이 곧 회고의 입구가 된다.
3. **회고 흔적 (Retro trace)**: 회고가 작성된 날은 월 미니 달력과 월간 칸에 작은 책갈피 표시. 칸 클릭 → 그날 할 일 + 회고를 함께 보는 패널.
4. **배치 대기 레일**: 날짜 없는 할 일을 레일에서 시간선으로 끌어 배치(지금의 드래그 이동 로직 재사용, 대상만 추가).

### 데이터 의존성 (구현 전 확인 필요)
| 항목 | 필요한 것 | 현황 |
|---|---|---|
| Ghost track | 날짜별 커밋/PR 목록 API | **미확인**. 없으면 BE 요청 문서(`docs/be-request-*.md`)로 분리. 시안은 샘플 데이터 |
| 하루 닫기 → 회고 초안 | 기존 회고 생성/AI 요약 API 호출 | 기존 흐름 재사용 가능한지 확인 필요 |
| 배치 대기 | 날짜 없는 할 일 조회 | `/todos` 데이터로 가능한지 확인 필요 |

위 3개는 로직을 유지한다는 전제에서 가장 큰 가정이다. API가 없으면 해당 기능은 시안에서만 보이고 구현 범위에서는 제외한다.

## 6. 컴포넌트 규칙

| 항목 | 값 |
|---|---|
| 간격 | 4px 단위. 행 높이 28/32/40 |
| 반경 | 입력·칩 6px, 카드·패널 8px, 아바타만 완전 원 |
| 선/그림자 | 헤어라인 1px. 그림자는 팝오버에만 `0 8px 24px rgba(0,0,0,.5)` |
| 타이포 | 본문 13–14px(앱 UI), 날짜 큰 숫자만 28–40px 500 weight, 시간·숫자는 Commit Mono + tabular-nums |
| 모션 | 120–180ms ease-out, 패널 슬라이드 200ms. `prefers-reduced-motion` 존중 |
| 포커스 | 2px `#5e6ad2` 링, 모든 인터랙션 키보드 접근 |
| 접근성 | 텍스트 대비 4.5:1 이상(ink-tertiary는 장식 전용), 상태는 색+아이콘/텍스트 병행 |

## 7. 키보드

`Ctrl+K` 팔레트 · `C` 퀵 캡처 · `T` 오늘 · `J/K` 이전/다음 · `D/W/M` 뷰 전환 · `Ctrl+Shift+F` 확대(기존) · `E` 선택 항목 상세 · `X` 완료 토글.

## 8. 시안 계획 (확정 후 진행)

현재 토큰 고정, 구조만 다른 시안 3개를 독립 HTML로 제작한다(앱 코드 미수정).

| 시안 | 구조 중심 | 주 레퍼런스 |
|---|---|---|
| A. Rail + Day | 좌측 레일, 일간 시간선 중심, 배치 대기, 하루 닫기 | Notion Calendar + Sunsama + Amie |
| B. Linear Rows | 사이드바 + 밀도 높은 행 리스트가 기본, 캘린더는 우측 미니 | Linear + Morgen |
| C. Command Week | 퀵 캡처 + 커맨드 팔레트 중심, 주간 그리드, Ghost track 강조 | Fantastical + Cron |

세 시안 모두 5장의 차별점(Ghost track, 하루 닫기, 회고 흔적)을 포함한다. 선택 후 `my-app/src/app/styles/`와 `widgets/app-shell`, `widgets/calendar-dashboard`로 이식한다.
