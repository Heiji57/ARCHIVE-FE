회고 시안

6~10 (새로 추가): 문서 작성 도구에서 흔히 쓰는 생각(글끼리 잇는 링크와 거꾸로 따라가기, 글 위의 속성 칸, 탭과 나란히 보기, 슬래시 블록, 찾기 창, 집중 모드)을 ARCHIVE 회고에 맞춰 다시 만든 시안입니다. 화면 배치, 아이콘, 색, 이름은 특정 제품을 따라 하지 않고 이 셸의 것을 그대로 씁니다. 본문에 [[ 를 치면 다른 회고를 걸 수 있고, #단어 는 태그가 되며, Ctrl K 로 찾기 창이 열립니다.

1~5 (앞서 만든 시안): 회고 페이지를 다섯 가지 구조로 만들었습니다. 지금 서비스의 기능(일간 · 주간 · 월간 · 연간 회고, 폴더, AI 요약 만들기, 그날 끝낸 일 · 커밋 재료, GitHub 저장)은 모두 그대로 넣었습니다. 시안마다 실제 페이지를 띄웠고 안에서 쓰기, 초안 만들기, 요약 만들기, 저장이 모두 됩니다. "이걸로 보기"를 누르면 상단 회고 탭이 그 시안으로 열리고 기억됩니다.
